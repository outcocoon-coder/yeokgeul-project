역글(易글) 양손 5열 완성형 키보드

왼쪽 3열은 자음, 오른쪽 2열은 모음으로 고정했습니다. 왼손 엄지로 자음, 오른손 엄지로 모음을 번갈아 누르는 흐름을 목표로 합니다.
⇅
한글↔역글 자동 변환
자음(초성/종성)
모음(중성)
마지막 입력
—
현재 해석
—
입력 설계
기본 원칙은 왼손 자음 → 오른손 모음 → 필요하면 왼손 받침입니다. 예를 들어 ☶(ㅅ) → ┃•(ㅏ) → ☱(ㄴ) 순서로 누르면 역글 ☶┃•☱, 한글 산이 됩니다.
자음과 모음이 같은 행에 있어도 역할이 좌우로 고정되어 있으므로, 탭이나 입력모드 전환이 필요 없습니다.
